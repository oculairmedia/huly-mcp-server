# Huly MCP Server v0.7 Migration Guide

## Overview

This guide covers the migration of the Huly MCP Server and REST API from v0.6 to v0.7, including the multistage build process that compiles SDK packages from the Huly platform source.

## What Changed in v0.7

### Platform Changes
- **Database**: MongoDB → CockroachDB
- **Message Queue**: Added Kafka for event streaming
- **SDK**: Packages must be built from Huly source (not available in npm)

### Breaking Changes
- SDK packages (@hcengineering/*) no longer published to npm
- Must build SDK from Huly platform source using Rush monorepo tools
- Connection initialization may have subtle timing differences

## Architecture

### Multistage Build Process

```
┌─────────────────────────────────────────┐
│  Stage 1: Build Huly SDK from Source   │
│  - Copy Huly platform source           │
│  - Install Rush build tools            │
│  - Build @hcengineering packages        │
└──────────────┬──────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────┐
│  Stage 2: Build MCP/REST API Server     │
│  - Copy built SDK from Stage 1          │
│  - Install remaining npm packages       │
└──────────────┬──────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────┐
│  Stage 3: Runtime Image                 │
│  - Minimal Alpine Linux                 │
│  - Application code + dependencies      │
│  - Non-root user for security           │
└─────────────────────────────────────────┘
```

## Building v0.7 Images

### Prerequisites

1. **Huly v0.7 Source**: Clone or extract Huly platform source
2. **Docker**: Version 20.10+ with BuildKit support
3. **Disk Space**: ~5GB for build process

### Quick Build

Use the automated build script:

```bash
cd /opt/stacks/huly-test-v07
./build-v07-stack.sh
```

This script:
1. Validates source directories
2. Builds MCP Server v0.7
3. Builds REST API v0.7
4. Tags images as `latest`
5. Displays build summary

### Manual Build

#### MCP Server

```bash
cd /opt/stacks/huly-test-v07/huly-mcp-server

# Copy Huly source to build context
cp -r "../hully source" "./hully source"

# Build image
docker build -t huly-huly-mcp:v0.7 -f Dockerfile.v0.7 .

# Cleanup
rm -rf "./hully source"
```

#### REST API

```bash
cd /opt/stacks/huly-test-v07/huly-rest-api

# Copy Huly source to build context
cp -r "../hully source" "./hully source"

# Build image
docker build -t huly-huly-rest-api:v0.7 -f Dockerfile.v0.7 .

# Cleanup
rm -rf "./hully source"
```

## Troubleshooting

### Build Failures

**Issue**: Rush build fails in Stage 1
```
ERROR: rush install failed
```

**Solution**: Ensure Huly source is complete and version-compatible:
```bash
cd "hully source"
git describe --tags  # Should show v0.7.x
```

**Issue**: Out of memory during build
```
ERROR: JavaScript heap out of memory
```

**Solution**: Increase Docker memory limit to 4GB+:
```json
{
  "memory": "4GB",
  "swap": "1GB"
}
```

### Runtime Connection Failures

**Issue**: REST API cannot connect
```
[Huly REST] ❌ Failed to connect to Huly: Login failed
```

**Solution**: Verify environment variables:
```bash
docker-compose exec huly-rest-api env | grep HULY
```

Ensure `HULY_URL=http://nginx` (internal Docker network, not external IP)

### SDK Version Mismatches

**Issue**: SDK incompatibility errors
```
TypeError: client.findAll is not a function
```

**Solution**: Rebuild images to ensure SDK matches platform version:
```bash
./build-v07-stack.sh
docker-compose up -d --force-recreate huly-mcp huly-rest-api
```

## Performance Considerations

### Build Time

- **Stage 1 (SDK Build)**: ~10-15 minutes (first time)
- **Stage 2 (Server Build)**: ~2-3 minutes
- **Total**: ~15-20 minutes per image

### Build Caching

Docker BuildKit caches each stage:
- Subsequent builds: ~2-5 minutes (if Huly source unchanged)
- Use `--no-cache` to force full rebuild

### Image Sizes

- **MCP Server**: ~400MB
- **REST API**: ~350MB
- **SDK Build Stage**: ~2GB (discarded in final image)
